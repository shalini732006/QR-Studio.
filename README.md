# QR Studio – QR Code Generator

QR Studio is a responsive web application that allows users to generate and customise QR codes easily using HTML, CSS, and JavaScript.

## ✨ Features

- Generate QR codes from text and URLs.
- Create QR codes for Wi-Fi credentials, email, and phone numbers (if supported by the current implementation).
- Customise QR code colours and styles.
- Choose from different themes.
- Download QR codes as PNG or SVG (if implemented).
- Copy generated content or QR output to the clipboard (if implemented).
- Responsive interface for desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – QR code generation and interactive features

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/shalini732006/QR-Studio.
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code if needed.

## 🎯 Project Objective

The goal of QR Studio is to provide a simple and user-friendly tool for generating and customising QR codes directly in the browser.
